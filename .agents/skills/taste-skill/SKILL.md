# Taste Skill (Leon Lin) — Anti-Slop Frontend

## The Three Dials
- **DESIGN_VARIANCE**: 1-10 (Control symmetry vs asymmetric composition)
- **MOTION_INTENSITY**: 1-10 (Control static vs dynamic micro-animations)
- **VISUAL_DENSITY**: 1-10 (Control airiness vs data density)

## Anti-Default Directives
- **Anti-Lila rule**: No generic AI-purple gradient glows. Use authentic, brand-calibrated single accent palettes (e.g. Phoenix Flame `#f97316` / `#fbbf24`).
- **Layout diversification**: Avoid centered 3-card clichés. Use split-screen, telemetry preview, and rhythm.
- **Eyebrow restraint**: Max 1 eyebrow label per 3 sections.
- **Single CTA intent**: Avoid duplicate CTAs with the same underlying action.
- **Single-line navigation**: Header fits on a single line at desktop with maximum 72px height.
