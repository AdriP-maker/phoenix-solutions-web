# Impeccable Design Skill (Paul Bakaus)

Out-of-distribution craft for AI coding agents. Focuses on production-grade code, visual hierarchy, cognitive load, accessibility (WCAG AA), responsive behavior, typography scale, spacing systems, and purposeful animations.

## Core Rules
- **No hedging, no shortcuts**: Deliverables must be complete without placeholder divs.
- **The brief wins**: Honor brand identity, pinned aesthetics, palettes, and typography.
- **Accessibility**: Strict WCAG AA contrast check on all buttons, forms, and cards.
- **Craft Floor**: Clean navigation, no duplicate CTA intent, rock-solid mobile collapse, predictable layouts.
